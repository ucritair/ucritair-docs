Mesh networking and Wi-Fi

How CAT's mesh network works, the MESH settings, and Wi-Fi.

Reticulum#

CAT's networking runs on Reticulum, a networking stack for building networks without central infrastructure. Its design principles are described in The Zen of Reticulum.

  • Uncentralizable. There is no central server or account system. Any device can carry traffic for any other, over radio, Wi-Fi, the internet or a serial cable.
  • Encrypted. Every message is end-to-end encrypted. Addresses are public keys, so no registration is needed.
  • Trustless. Relays carry packets they can't read.

Each CAT is a first-class node, and every CAT that switches on grows the network. A node does four jobs.

Messaging#

CAT sends and receives encrypted messages and doodles, with other CATs and with LXMF apps on phones and computers. See Chat.

Routing#

CAT is a Reticulum transport node. It forwards all Reticulum traffic for the network, so traffic between any two devices can travel through your CAT.

Bridging LoRa and IP#

When CAT is on Wi-Fi, it connects the LoRa radios around it to the Reticulum network on the internet. Anyone nearby with a LoRa radio, such as an RNode used with Sideband, can reach people anywhere through your CAT.

Store and forward#

CAT is an LXMF propagation node. It stores LXMF messages for anyone who is offline, syncs them with other propagation nodes, and delivers them when the recipient reappears. As you carry it around, it picks up mail from the radio neighbours it meets, and passes it on when it connects to other mail nodes, such as its home hub.

NTN (satellite) and BLE messaging are in development.

How the mesh works#

TermMeaning
LoRaThe long-range, low-power radio built into CAT. CATs within radio range talk to each other directly, with no phone network, Wi-Fi or internet needed.
ReticulumThe networking system CAT uses. It finds paths between devices and encrypts everything end to end.
LXMFThe message format on top of Reticulum, shared with apps like Sideband and NomadNet.
Transport nodeA node that forwards all Reticulum traffic for the whole network: packets, announces, path requests and links. Every CAT is a transport node by default.
Propagation nodeA node that propagates all LXMF messages: it stores messages for anyone who is offline, syncs them with other propagation nodes, and delivers them when the recipient reconnects. Every CAT is a propagation node by default, and uses one (its mail node) for its own messages that can't be delivered directly.
TCP bridge and hubsOver Wi-Fi, CAT connects to a public Reticulum hub on the internet. That links the CATs around you to the rest of the network, and lets you reach friends far away.
SanctuaryThe project's home hub. CATs connect to it first and also use it as their default mail node.

The radio's frequency and other settings are fixed when CAT is set up. CATs hear each other when they use the same radio settings.

Mail node: HOME, AUTO or OFF#

  • HOME (default): use Sanctuary's mailbox whenever your CAT has a working internet route to it. Without one, CAT picks the best nearby node instead and switches back when the route returns. Home is never looked for over LoRa.
  • AUTO: always pick the best node CAT can find, over radio or internet.
  • OFF: deliver directly only. Messages to unreachable friends fail instead of waiting in a mailbox.

Switching mail node doesn't move messages already waiting on the old one. A custom node can be set from the USB shell; the menu then shows MAIL NODE: CUSTOM.

TCP BRIDGE and hubs#

The TCP bridge needs Wi-Fi. By default it uses a built-in list of 32 public hubs, starting with Europe - Sanctuary (home). If a hub stops answering, CAT moves to another one and later tries home again.

RowWhat it does

CHOOSE HUB FROM LISTStart from a different hub in the list. CAT still moves on if it fails.

USE AUTOMATIC LISTShown only on a custom hub: go back to the built-in list.

Wi-Fi#

Settings → SETTINGS → WIFI. Wi-Fi is used for the TCP bridge and for Crypto uploads. Your networks and passwords are stored on CAT's board controller and survive resets and game updates. Up to 8 networks are remembered, most recent first.

Joining a network#

  1. Choose SCAN NETWORKS. After SCANNING Please wait..., nearby networks are listed.
  2. Pick yours. The keyboard opens for the password (leave it empty for an open network) and press DONE.
  3. Check the password shown on CONNECT TO and choose CONFIRM.
  4. Wait for SUCCESS Connected, and press A. A network you connect to is saved automatically.
Passwords are shown in plain textThe Wi-Fi screens display the password as you typed it, so check who can see your screen.

If it fails you see FAILURE with Connection failed, No response, No networks found or Scan failed.

Saved networks and adding by hand#

  • SAVED NETWORKS lists remembered networks and has the AUTOCONNECT switch. With it on, CAT reconnects by itself when it is offline and idle. Pick a network to see its security type and CONNECT or FORGET it. FORGET acts immediately.
  • ADD NETWORK is for hidden networks: type the name, optionally a password, and SAVE. With a password it is saved as WPA2, without as open.
  • Untick WIFI ON to turn the Wi-Fi radio off. LoRa keeps working; the TCP bridge waits.

CAT joins open, WEP, WPA and WPA2 networks.

What happens to a message#

  1. If your friend is one radio hop away or reachable over the internet link, CAT sends it straight there and waits for a delivery receipt (two green ticks).
  2. If they are farther, CAT tries directly once, then gives the message to its mail node (one tick and a dot), retrying after 1, 2 and 4 minutes.
  3. If CAT has never heard of the recipient, it asks the network and waits up to 3 minutes.
  4. When your friend's CAT comes online, it collects its mail from the propagation node.
